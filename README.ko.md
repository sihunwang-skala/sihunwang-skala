## 대표 프로젝트

### [개인화 건강 코칭 Multi-Agent](https://sihunwang-skala.github.io/sihunwang-portfolio/health-agent/)

**역할:** 고령 제2형 당뇨병 환자를 위한 챗봇에서 LangGraph Supervisor와 전문 Agent Workflow, 개인 조건을 반영한 Retrieval, 안전 처리 및 평가 설계.

**결과:** 200문항 Benchmark에서 181/200(90.5%) 통과, Single-Agent 구조의 165/200(82.5%) 대비 16문항 증가. 별도 100문항 평가에서 건강 코칭 외 요청 39/40 처리. 개별 Agent의 효과가 아닌 전체 시스템 비교 결과.

[Case Study](https://sihunwang-skala.github.io/sihunwang-portfolio/health-agent/) | [Technical Report (PDF)](https://sihunwang-skala.github.io/sihunwang-portfolio/health-agent/report.pdf)

### [L10n Quality Agent](https://sihunwang-skala.github.io/sihunwang-portfolio/l10n-agent/)

**역할:** 오류 유형별 번역 수정 Chain, 남은 오류에 따른 Strategy Selection, 숫자와 용어 검증, Rollback, 미해결 사례의 HITL 승인 Workflow 개발.

**구현:** LangChain LCEL, MQM Error Routing, 보호 용어 처리, Retry 제어.

[Case Study](https://sihunwang-skala.github.io/sihunwang-portfolio/l10n-agent/) | [프로젝트 README](https://github.com/sihunwang-skala/l10n-quality-agent)

### [납세 검증 및 농업통계 데이터 Pipeline](https://sihunwang-skala.github.io/sihunwang-portfolio/#proj-pipeline)

**역할:** 국세청 API와 웹 데이터 수집, 식별자 매핑, 오류 분류 및 Excel 갱신 자동화. Excel 30개 시트, 총 11,205행 및 3,550열에서 고유 식별번호 645건을 처리하고 2,346셀 자동 기입.

**결과:** 주간 갱신 시간 60분에서 10분으로 단축, API 실패 45건 재처리.
