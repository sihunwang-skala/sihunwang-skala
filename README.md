### [Personalized Health Coach Multi-Agent](https://sihunwang-skala.github.io/sihunwang-portfolio/health-agent/)

- **Core skills:** LangGraph, Multi-Agent Orchestration, Agentic RAG, Hybrid Retrieval, LLM Evaluation, HITL
- **Role:** Designed Supervisor routing, specialized agent workflows, personalized evidence retrieval, safety handling, and system-level evaluation for a health-coaching chatbot.
- **Result:** Passed **181/200 questions (90.5%)**, versus **165/200 (82.5%)** for a Single-Agent system. Handled **39/40 non-coaching requests (97.5%)** in a separate 100-question evaluation.

### [Tax Verification & Agricultural Statistics Pipeline](https://sihunwang-skala.github.io/sihunwang-portfolio/#proj-pipeline)

- **Core skills:** Python, REST API Integration, Selenium, BeautifulSoup, OpenPyXL, Data Validation, Error Handling
- **Role:** Built an automated data pipeline for tax verification, identifier mapping, error recovery, and updates across **30 Excel sheets totaling 11,205 rows and 3,550 columns**; processed **645 unique identifiers** and populated **2,346 cells**.
- **Result:** Reduced weekly update time from **60 to 10 minutes** and successfully reprocessed **45 failed API requests**.
