## Selected projects

### [Personalized Health Coach Multi-Agent](https://sihunwang-skala.github.io/sihunwang-portfolio/health-agent/)

**Role:** Designed the LangGraph Supervisor and specialized agent workflow, personalized retrieval, safety handling, and evaluation for a health-coaching chatbot for older adults with type 2 diabetes.

**Result:** Passed 181/200 questions (90.5%) in a benchmark, compared with 165/200 (82.5%) for the Single-Agent architecture. Handled 39/40 non-coaching requests in a separate 100-question evaluation. These are comparisons of complete systems, not isolated effects of individual agents.

[Case study](https://sihunwang-skala.github.io/sihunwang-portfolio/health-agent/) | [Technical report (PDF)](https://sihunwang-skala.github.io/sihunwang-portfolio/health-agent/report.pdf)

### [L10n Quality Agent](https://sihunwang-skala.github.io/sihunwang-portfolio/l10n-agent/)

**Role:** Built a translation review workflow with category-specific revision chains, error-based strategy selection, deterministic checks, rollback, and human approval for unresolved cases.

**Implementation:** LangChain LCEL, MQM error routing, protected terms, and retry controls.

[Case study](https://sihunwang-skala.github.io/sihunwang-portfolio/l10n-agent/) | [Project README](https://github.com/sihunwang-skala/l10n-quality-agent)

### [Tax verification and agricultural statistics pipeline](https://sihunwang-skala.github.io/sihunwang-portfolio/#proj-pipeline)

**Role:** Connected the National Tax Service API, web sources, identifier mapping, error triage, and Excel updates. Processed 30 Excel sheets totaling 11,205 rows and 3,550 columns, with 645 unique identifiers and 2,346 automatically populated cells.

**Result:** Reduced weekly updates from 60 to 10 minutes and reprocessed 45 failed API requests.
